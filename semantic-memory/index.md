# Semantic Memory Index

This index exists so a task can be matched against relevant knowledge pages **without opening every page**: `summary` and `keywords` here are copies of each page's own frontmatter, kept in sync by `memory-ingest` whenever a page is added or updated. If this file and a page's frontmatter ever disagree, the page's frontmatter is authoritative — treat a mismatch as a sign this index is stale and needs re-syncing.

Pages are grouped by the stage of the traffic simulation pipeline they belong to (network creation → demand generation → signal control/optimization → simulation run → post-processing), matching the taxonomy `curriculum-agent` uses to find gaps. A category with no pages is left in place on purpose — an empty section is a visible gap, not a formatting omission.

Conventions for adding a new page: keep it alphabetical within its category; keep the summary to one line (copy it verbatim from the page's frontmatter, don't paraphrase separately); list keywords comma-separated in the same order as the page's frontmatter.
